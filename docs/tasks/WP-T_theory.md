## Required content (each item: statement, explicit assumptions, complete proof, a counterexample showing
which assumption matters, and the experimental prediction with the variable that tests it)
1. **Output subspace and input bottleneck** (§6.1): fixed M ⇒ δy ∈ col(B); A x₁ = A x₂ ⇒ equal branch output;
   Jacobian rank ≤ r where differentiable. Counterexample: the sequence-level Jacobian through the memory path
   can exceed rank r (construct one).
2. **Linear reader = memory polynomial** (§6.2): φ = id ⇒ z^{(L)} = Σ_{j=0}^{L} T^j u, T = ρ(R + U M Q).
   Corollary for `t2_chain_end` with orthonormal codes and exact storage (λ = β = 1): give conditions on
   (ρ, U, Q, R) under which the readout's argmax is the chain terminal for every L ≥ h and the hop-L node for
   L < h; state what happens with random (non-orthogonal) codes as load E/r grows (interference terms and their
   amplification with L, using the §6.5 bound).
3. **Single-read limits** (B4 and V2-FQ): the output depends on M only through one linear read M Q u. Construct
   episode pairs with identical first-hop read but different terminals and derive an upper bound on multi-hop
   accuracy of any single-read reader under the generator's distribution (WP-B `t2_chain_end`, chains as in the
   prereg); compare with the chance level actually used (candidate set).
4. **ReLU without bias** (V2 as specified, no bias term): show the obstruction to passing a signed value code
   through `Q φ(U v)` with an r-wide ReLU (e.g. the image of v ↦ Q φ(U v) lies in a cone generated by r vectors,
   so no such map is the identity on a set that positively spans R^r). Quantify for random codes if you can
   (fraction of codes outside a simplicial cone), and state what changes with a bias or width > r. Prediction:
   M1 (ReLU) vs M1-lin on pointer chasing.
5. **Contraction and stopping** (§6.3): fixed point, the e_s/(1 − c) bound, the factorised bound on c; note why
   chain-following solutions in item 2 are typically non-contractive (ργ > 1) and what that implies for the
   stopping rule (P4 of the plan).
6. **Exact elimination** (§6.4) and the non-equivalence A φ(B z) ≠ φ(A B z), with a 2-D counterexample.
7. **Original proposal** (§1.3): (BA)^L = B(AB)^{L−1}A; zero-gradient start of the double-BA branch at B = 0
   (first-order and second-order statement) and why the skip form starts.
