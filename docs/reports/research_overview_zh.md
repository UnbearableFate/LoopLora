## 模型与记号

LoopLora 在冻结的预训练线性层 $W$ 旁边加一个低秩分支，分支里有一个固定大小的上下文记忆 $M\in\mathbb R^{r_m\times r_m}$。上下文 token 由写入器写进 $M$，当前 token 由读取器对同一份 $M$ 查询 $L$ 次。主干的每个算子每次前向只执行一次，增加 $L$ 只增加低维读取的计算，不增加写入次数。记号以 `docs/notation.md` 为准。

写入器采用先衰减后修正的 delta 规则：

$$
u=Ax,\qquad k=\frac{Ku}{\max(\lVert Ku\rVert_2,\ \epsilon)},\qquad v=Vu,\qquad \bar M=\lambda M_{\mathrm{prev}},\qquad M_{\mathrm{new}}=\bar M+\beta\,(v-\bar M k)\,k^\top
$$

读取器（V2，主候选 M1）对写入前的同一快照 $M_{\mathrm{prev}}$ 迭代 $L$ 步：

$$
z^{0}=u,\qquad q^{s}=Qz^{s},\qquad m^{s}=M_{\mathrm{prev}}\,q^{s},\qquad z^{s+1}=u+\rho\,\phi\!\left(Rz^{s}+Um^{s}\right),\qquad s=0, \dots, L-1
$$

$$
y=Wx+b_W+\alpha B z^{L}
$$

其中 $r$ 是秩，$r_m$ 是记忆维度（默认 $r_m=r$），$\phi$ 是 ReLU，$\rho=0.25$，$\alpha=1$。$L=0$ 时 $z=u$，分支就是普通 LoRA $\alpha BAx$。

实验中比较的读取器都装在同一插入位置（`docs/notation.md` §6）：

| 记号 | 做法 | 读记忆的次数 |
| --- | --- | --- |
| B3 | 无记忆循环，$z^{s+1}=u+\rho\phi(Rz^{s})$ | 0 |
| B4 | V2 取 $L=1$，即同秩单次读取 | 1 |
| B5 | 固定查询，只读一次 $m=M_{\mathrm{prev}}Qu$，再循环 $L$ 步 | 1（缓存） |
| M1 | 上式的迭代查询，各步共享 $R, U, Q$；默认在 $L\in\{1,2,4\}$ 上混合训练 | $L$ |
| M1-lin | M1 把 $\phi$ 换成恒等映射 | $L$ |
| M1-L4 | 只在 $L=4$ 训练的 M1 | 4 |
| B8 | 每步一套独立的 $R_s, U_s, Q_s$，固定 $L=4$ | 4 |
| B6 / B7 | 秩更大 / 记忆维度更大的单次读取 | 1 |

M1-L4 与 B4 的参数完全相同。B8 多出 $3(r^2+2rr_m)$ 个参数：在 LLM 适配器中，$r=r_m=32$ 时多 9,216 个（+8.9%），$r=r_m=128$ 时多 147,456 个（+31.0%）；在符号阶段的 joint 模型中多 69.2%（`docs/paper/evidence_symbolic.md` FR1）。

写入器有几种条件，结论按条件分开陈述：

- `oracle_orth`、`oracle_random`：用固定的正交或随机实体码，按事实表直接写入（$\lambda=\beta=1$），用来单独检验读取器。
- `joint`：写入器与每个读取器一起训练，key 和 value 来自同一个 $u$。
- `joint_fact`（分解式）：key 只看 head 和关系，value 只看 tail。
- `t1_frozen`、`t1_frozen_fact`：先在单跳任务 T1 上训练写入器，然后冻结。
- LLM 阶段另有 learned writer 和 LLM 版 `oracle_random`。LLM 版的 key 是独立的随机（实体，关系）码，value 取自另一张随机实体码表，所以和符号 oracle 不同（`docs/paper/evidence_llm.md` LP2、LP6）。

主任务 `t2_chain_end`：每个 episode 写入 $E=12$ 条事实，组成长度为 8 和 4 的两条链，共 14 个候选实体。问题给出起点和关系，答案是沿链走到的终点。训练 hop 1-3，评估 hop 1-8。符号阶段的主指标是候选集内准确率（随机水平 $1/14\approx7.1\%$），LLM 阶段的主指标是全词表 EM。

对同一个 checkpoint 改变 $L$ 时，记

$$
D=\mathrm{Acc}_{L=4}-\mathrm{Acc}_{L=1}\ (\text{hop }2,3),\qquad F=\text{同样的差}\ (\text{hop }6,7,8),\qquad W=D-F,\qquad H=\text{同样的差}\ (\text{hop }1)
$$

$D$ 是可达 hop 上的深度收益。4 次读取走不到 hop 6-8，所以 $W>0$ 说明收益集中在走得到的 hop 上。$H$ 衡量多读之后 hop 1 是否受损，即读取越过链尾（overshoot）的代价。

## 正在研究的问题

核心问题：在冻结主干、相同秩 $r$、相同记忆大小和相同写入次数下，让低维查询对同一份记忆多读几次，能否完成单次读取做不到的关系组合，也就是沿事实链走多跳？比较对象是同秩的单次读取 B4，多出的读取延迟算作代价（计划附录 E.2，2026-10-27 用户决定；`plan/recurrent_lora_research_plan_2026-10-26.md`）。项目不把“共享 LoRA 并循环使用”本身当作创新：RecLoRA、固定快权重上的多次读取（Ba 等 2016）、Generative Adapter 和 δ-mem 已经覆盖了相邻设计（计划 §0.1）。

围绕这个问题有五件事要分开回答：

- 深度：同一 checkpoint、相同输入和记忆下，$L$ 从 1 增到 4 能否提高多跳准确率；收益是否来自随步演化的查询，而不能由无记忆循环 B3 或固定查询 B5 解释（计划 §3 的 H1-H3）。
- 写入器：learned writer 写出的码能不能被多次读取组合；准确率会不会来自不沿链走的捷径。
- 预算：同秩单次读取以及更大秩或更大状态的单次读取能否达到同样效果，参数和延迟代价各是多少。
- 停止：读取次数超过 hop 数时答案会不会被破坏，能否按问题自适应停止。
- 迁移：放进 Qwen3-0.6B-Base 的单个模块后，以上结论是否仍然成立。

### 理论给出的约束

`docs/theory.md` 的 11 个命题都是在各自假设下的局部推导，用来约束实验的解读，不能代替实验证据。

**精确走链需要增益大于 1。** 实体码 $c_i$ 两两正交且 $\lambda=\beta=1$ 时，delta 写入恰好得到 $M=\sum_{i\to j}c_jc_i^\top$。取起点输入 $u=c_{i_0}$ 和 $R=0,\ Q=I,\ U=\gamma I$ 的线性读取器，hop 为 $h$ 的问题在第 $L$ 步的状态是 $z^{L}=\sum_{j=0}^{\min(L, h)}a^{j}c_{i_j}$，其中 $a=\rho\gamma$。在这个构造里，只有 $a>1$ 时终点才在 $L\ge h$ 之后稳定胜出；$\rho=0.25$ 时需要 $\gamma>4$（命题 3）。也就是说，这种精确走链的读取算子欧氏增益大于 1，不是收缩映射。

**非正交 key 让后写的事实改动先写的事实，误差还会随读取深度放大。** $\lambda=\beta=1$ 时 $M_E=\sum_i v_ik_i^\top P_{i+1}\cdots P_E$，$P_i=I-k_ik_i^\top$。加性存储时 $Sk_a=v_a+\sum_{i\ne a}v_i\langle k_i, k_a\rangle$，独立各向同性单位 key 下交叉项平方范数的期望是 $(E-1)/r$。记忆误差经 $L$ 次读取的上界为

$$
\lVert z^{L}-\tilde z^{L}\rVert\le d\,\lVert u\rVert\sum_{j=1}^{L}j\,\kappa^{\,j-1},
$$

$\kappa>1$ 时可以几何增长（命题 4）。对应的可检验预测是：负载 $E$ 增大时，深度收益缩小。

**实际 delta 读取的系数由 key 的 Gram 矩阵决定。** $M_Eq=\sum_i d_iv_i$，$d_i=\beta\lambda^{E-i}a_i$，$a=(I+\beta C_+)^{-1}b$，其中 $b_i=k_i^\top q$，$C_+$ 是 key Gram 矩阵的严格上三角部分（命题 11）。key 越相关，读出的向量越偏离被查询的 value。

**单次读取的信息上限是有条件的。** B4 和 B5 只通过 $m=MQu$ 看到记忆，观察相同则预测必然相同。在精确正交存储且首跳查询对齐的条件下，hop $h\ge2$ 的准确率不超过 $1/(N-2)$（$N$ 为候选实体数）；对不受约束的 $Q$ 则没有普适上界（命题 5）。

**learned writer 可以走捷径猜终点。** 同一关系的事实共用一个 key 时，delta 存储退化成 value 的指数加权和 $m_E=\beta\sum_i a^{E-i}v_i$，$a=\lambda(1-\beta)$。$\lambda\approx1$、$\beta$ 较小时它接近等权和；如果 value 编码的是 $D(e_t-e_h)$，链上的和会望远镜相消成 $\sum_j D(e_{T_j}-e_{R_j})$（$T_j$、$R_j$ 是各链的终点和起点），模型不沿链走也能得到终点集合（命题 10）。理想的猜终点策略在各 hop 上准确率持平（三种链布局下分别为 50%、50%、33.3%），在保持终点集合、只交换后继的反事实（swap_successors）下没有提升。分解式写入器只让 value 看 tail，能去掉直接的 head 相减项，但不能排除所有全局捷径。

另外两条：收缩条件 $c=|\rho|L_\phi\lVert H\rVert_2<1$ 只保证唯一不动点和状态误差界，与答案是否正确无关（命题 7）；无偏置 ReLU 不能把正负号混合的码原样传给下一次查询（命题 6），所以符号阶段把恒等激活的 M1-lin 与 M1 并列检验。

### LLM oracle 读取器线

**P1-L：LM 内的多次读取（主研究）**

- 假设：在 Qwen3-0.6B-Base 的单个模块中，用 oracle 写入器提供记忆时，固定 $L=4$ 训练的多次读取器在 hop 2-3 上胜过同秩单次读取 B4。修订 B7 登记的预测是 r=32 不通过记忆使用检查，r=128 通过。
- 设计：主干 `Qwen/Qwen3-0.6B-Base`（固定 revision），模块位于第 14 层 `o_proj`（2048→1024），适配器和状态用 fp32。采用 memory-only 协议，支持文本写入记忆后不再留在主干的注意力 KV 中。任务同上（E=12，链 (8,4)，4 种关系）。写入器是 LLM 版 `oracle_random`。读取器 B8（主）、M1-L4、B4、B5-L4、B3-L4，分 $r=r_m=32$ 和 $r=r_m=128$ 两个条件，每个 3 个 seed，各训练 17,000 步；B0、B1、B2 作为不参与门限的基线。确认集为 test 区间 [100000, 102000) 的 2,000 个 episode，配对 bootstrap 2,000 次，受检条件 k=2，所以用 97.5% 区间。另登记了逐步读出（logit lens 和名字 logit 梯度方向）作为描述性终点。
- 判定：
  - B7 记忆使用检查最先看：在 hop 1 全词表 EM 上，B4@1、B8@4、M1-L4@4 都要高于 B3-L4@4，且 97.5% CI > 0。某个秩不通过，就报告为读取器没有学会使用 oracle 记忆，该秩的门限结果照常列出，但不作为多次读取的正面或反面证据。
  - G1-L：B8@4 − B4@1 ≥ 3 pp，CI > 0，且每个 seed 都为正；hop 1 上 B8@4 − B4@1 ≥ −1 pp（点估计）；在 `t2_typed`（3 个同 head 干扰事实）上复现，CI > 0。
  - G2-L：B8@4 分别高于 B5-L4@4 和 B3-L4@4，CI > 0。
  - 修订 B6：只有 M1-L4@4 − B4@1 同样满足 G1-L 的标准，才能说参数相同时多读胜过单读。
  - 无论门限结果如何，r=32 不做多次读取结论。r=128 通过只说明读取器在 LM 内学会了第二跳起的 value→key 查表并组合了多次读取，不等同于符号 oracle 的结论，也不涉及 unseen 名字。
- 出处：`docs/prereg/P1L.md`（v2 及修订 B1-B7）。

**P1L-C：r=128 读取器的因果与读取位置分析**

- 假设：r=128 的多次读取器给出的答案，因果地依赖第一次读取后状态 $z_1$ 携带的桥实体。
- 设计：只评估，不训练。对象是 r=128 的 M1-L4、B8、B4，使用新区间 test [102000, 104000)。分析 A 让除最后一个问题位置外的其他位置都读 $M=0$，比较 EM，只作描述。分析 B 针对 hop-2 问题构造三个只改第一条边的记忆：世界 A 是原图 $s\to b_A\to t_A$；世界 B 是 $s\to b_B$，$b_B$ 是另一条链最后一条边的 head；世界 C 是 $s\to c$，$c$ 没有出边。在世界 A 中把 $z_1$ 换成世界 B 或 C 的 $z_1$，或者加一个同范数的随机方向，之后各步仍读世界 A 的记忆。
- 判定：定义偏移量

  $$
  \mathrm{shift}=P(t_B\mid \text{B 补丁})-\max\big(P(t_B\mid \text{C 补丁}),\ P(t_B\mid \text{随机补丁})\big)
  $$

  合并后 shift ≥ 10 pp、95% CI > 0、且每个 seed 都为正，才做因果桥接结论；否则逐步读出只作为解码结果报告。
- 运行条件：r=128 通过 B7 检查。出处：`docs/prereg/P1L-C.md`（含澄清 C1）。

**WP-L6：r=32 下的 oracle 编码 pilot**

- 假设：r=32 读不动 LLM oracle 记忆，是因为 LM 通路要学三张随机映射：问题状态到随机 key、value 码到下一跳 key、value 码到名字（修订 B7 的推断）。让 key 与 value 相关（O-rot），或让码表可学（O-shared），r=32 的读取器就能用上记忆。
- 设计：M1-L4，$r=r_m=32$，lr 3e-3，seed 17，训练 5,666 步，其余与 P1-L 的 r=32 条件相同，只用验证集（val，seed 4242，1,000 个 episode）。两个臂：
  - O-rot：$k=\mathrm{normalize}(\Pi_\rho g_h)$，$v=g_t$。$g$ 是 P1-L 的随机实体码，$\Pi_\rho$ 是每种关系一个固定随机正交矩阵，于是从桥实体 value 到下一跳 key 是固定的线性映射 $\Pi_\rho$。
  - O-shared：可学习码表 $C\in\mathbb R^{1025\times32}$，初始化为 $g$；$k=\mathrm{normalize}(\Pi_\rho C_h)$，$v=\mathrm{normalize}(C_t)$。码表与读取器一起训练，记为写入器参数（32,800 个）。
- 判定：最终 checkpoint 在 $L=4$ 下的 hop-1 全词表 EM ≥ 30% 即通过，只看这一格。O-rot 通过就选 O-rot；否则 O-shared 通过就选 O-shared；都不通过则 LLM r=32 的 oracle 线停止。参照值是 P1-L Pilot-2 中 M1-L4 的 hop-1 EM 0.1%。O-rot 只修第二跳起的转移；如果只有 O-shared 通过，说明 r=32 的瓶颈在 LM 两端的随机映射。pilot 本身不做多次读取结论。
- 出处：`docs/prereg/WP-L6.md`。

**P1L-S：用新编码在 r=32 重做 P1-L**

- 假设：换成 WP-L6 选出的编码后，r=32 的 LM 内多次读取胜过同秩单次读取，与符号阶段在同一秩上的结论对应。

- 运行条件：WP-L6 的决定为 selected，与 P1-L 在 r=128 的结果无关。出处：`docs/prereg/P1L-S.md`。

### LLM learned writer 线

WP-L4 之后没有选出写入器，诊断指向读取失真（见下一节 LLM 部分）。三项研究共用 WP-L4 的 T1 设定：单跳任务，E=16，4 种关系，head 共享比例 0.3，seed 17，第 14 层 `o_proj`，$L=1$，batch 32，lr 3e-3，在 1,000 个验证 episode（seed 4242）上选择。基础目标 R 是 W5（输入标准化、InfoNCE 寻址损失、干净 value 的交叉熵）加上原始读取损失。共同门限：最终 checkpoint 的 val EM ≥ 0.80 即选中；没有臂达到 0.80、但最好的臂达到 0.50 时，该臂在 E=8 重训一次，重训后 ≥ 0.80 则接受并标记。

**RFX：读取失真的因子诊断**

- 假设：WP-L4 的读取失真可以归到存储、查询或解码中的某一环。
- 设计：冻结 WP-L4 的 R-r128、R-r32 和 W5-r32 三个 checkpoint，只替换最后一个问题位置的读取，其他位置和之后的 LM 通路不变。存储取部署的 delta 状态，或 ridge 存储 $M=VK^\top(KK^\top+\eta I)^{-1}$；查询取原始 $q$、单位化 $q$ 或被查询事实的真实 key；另有干净 value 和零读取两个对照，每格再拟合一个标量增益。$\eta$ 只在训练集 episode 上选。解码器有三个：原 LM 通路（D1，全词表 EM）、训练用的干净 value 头（D2）、在拟合集读取上重拟合的线性解码器（D3）。评估用 val [200000, 204000) 的 4,000 个问题。
- 判定：一格算作救回，要求归一化读取误差不超过基线的一半，且 EM 提高 ≥ 10 pp。按顺序取第一个成立的判定：
  1. 存储：ridge 加原始 $q$ 救回，或 ridge 加单位 $q$ 救回而 delta 加单位 $q$ 不能。触发 LSQ 的 K4 和 RG 臂。
  2. 归一化：delta 加单位 $q$ 救回。触发 LSQ 的 U 臂。
  3. 查询：delta 加真实 key 救回。
  4. 存储加查询：只有 ridge 加真实 key 救回。
  5. 解码：D3 比限定在 1,024 个实体上的 EM 高 ≥ 10 pp。
  6. 都不成立：无法区分。

  后四种不触发 LSQ。每个秩跟随该秩 R checkpoint 的判定。
- 出处：`docs/prereg/RFX.md`。

**DPFP：特征映射后再写入和读取**

- 假设：把 key 和 query 经无参数的 DPFP 特征映射（Schlag 等 2021）升到更高维的非负空间，存储的 key 更接近正交，读取失真随之消除，从而得到通过门限的写入器。
- 设计：$\hat k=\phi_\nu(k)/\lVert\phi_\nu(k)\rVert_2$，$\hat q$ 同理，其中 $\phi_\nu(x)=\big[\,\mathrm{ReLU}(x')\odot\mathrm{roll}(\mathrm{ReLU}(x'),j)\,\big]_{j=1,\dots,\nu}$，$x'=[x;-x]$，记忆变为 $M\in\mathbb R^{r_m\times 2r_m\nu}$。三个臂 D32-3（r=32，ν=3）、D128-1、D128-3，每臂一个不超过 2 小时的作业，步数由 10% smoke 的计时决定。
- 判定：按 D32-3、D128-1、D128-3 的顺序，第一个 val EM ≥ 0.80 的入选；都不到时按共同门限处理 E=8 重训；否则不选。修订 A1 规定：DPFP 同时改了特征几何和查询归一化，报告不能把效果只归给去相关。
- 出处：`docs/prereg/DPFP.md`。

**LSQ：回归式存储**

- 假设：E=16 ≤ r 时存在能精确插值的存储。用最小二乘插值或逼近插值的存储代替单遍 delta，并用单位查询读取，可以消除读取失真。
- 设计：所有臂都用单位查询 $\hat q=q/\lVert q\rVert$。RG 臂用加近因权重的 ridge 存储 $M=VWK^\top(KWK^\top+\eta I)^{-1}$，$W=\mathrm{diag}(\lambda^{E-1-j})$，$\eta$ 取 RFX 选出的值并截断到 [1e-4, 0.1]。K4 臂把 $\beta=1$ 的 delta 扫描重复 4 遍（Kaczmarz 迭代）。U 臂保留部署的 delta 存储，只把查询单位化。
- 运行条件：RFX 对某个秩判为存储，就在该秩跑 K4 和 RG；判为归一化，跑 U；其他判定不跑。
- 判定：候选顺序 L32-U、L32-K4、L32-RG、L128-U、L128-K4、L128-RG，门限与 DPFP 相同。DPFP 与 LSQ 都选出写入器时，P1L-D 用秩较低的；同秩取 val EM 较高的；再相同取 DPFP。两者都没有选出（或 LSQ 未被触发且 DPFP 没有选出），learned writer 线停止，论文报告负结果。
- 出处：`docs/prereg/LSQ.md`。

### 符号阶段的后续研究

以下研究都在 $r=r_m=32$、训练 seed 17/29/43 上进行。需要新评估的研究各用一个此前没用过的 eval seed；NCR 和 UNS 的 Part A 只复用已有样本。

**IVD：把干扰和负载分开**

- 假设：IS 研究中深度收益随负载缩小，是由 key 重叠造成的干扰，而不只是存储事实变多、相关事实变旧或任务分布改变。
- 设计：冻结的 M1 与 B4（oracle_random、joint_fact），确认集 eval seed 999004。目标链、问题、答案和候选集合都不变，只加入路径外的事实（head 在 episode 外，tail 在 episode 内）。额外负载分 L6、L24 两档（共 18、36 条事实），key 重叠分 low、nat、high 三档：oracle 下直接构造（high 档与某条相关事实的 key 余弦为 0.5），joint_fact 下按实测重叠挑选。同一负载内槽位、tail 和写入顺序都相同；joint_fact 另设只衰减不写入的对照。
- 判定：记 $G=\mathrm{Acc}_{L4}-\mathrm{Acc}_{L1}$（M1，L24，hop 2-3），$IC=G(\text{low})-G(\text{high})$。IC ≥ 5 pp 且 97.5% CI 下界 > 0，则该写入器上的干扰解释成立；否则论文撤回把干扰作为 IS 结果的已识别解释。high 与 low 的实际重叠差小于 0.2 时标为 inconclusive，动作相同。
- 出处：`docs/prereg/IVD.md`。

**CVH：用继续读取的价值训练停机头**

- 假设：停机头如果在 hop-1 约束下选阈值（A1），或者改为预测之后再读能否降低答案损失（A2），就能在不损失 hop 1 的前提下停机。
- 设计：P4-S-L 的 9 个冻结 M1（oracle_random、joint_fact、t1_frozen_fact，各 3 个 seed）。A0 是 P4-S-L 原停机头，作参照。A1 用同一个头，阈值只在验证集 hop-1 损失 ≤ 1 pp 的范围里选。A2 是同尺寸的新头（51→64→1，3,393 个参数），第 $s$ 步的标签为：之后没有任何一步的候选交叉熵比当前低 0.25 nats 以上，则停。确认集 eval seed 999005。
- 判定：每族每臂要同时满足：hop 2-3 比 L1 高 ≥ 3 pp 且 CI > 0，hop-1 损失 ≤ 1 pp，平均执行步数 ≤ 8，区间水平 $1-0.05/6$。只有端到端实测的停机时间短于固定 L16，才声称延迟上的改进。验证集上没有阈值能保住 hop 1 的臂直接判失败，不看确认集。
- 出处：`docs/prereg/CVH.md`。

**TSM：训练时加入终态约束**

- 假设：训练时要求答案在链尾之后的每一步都可解码，或再加内容门控的粘滞更新，可以消除越过链尾的损失，同时保住长链准确率和相对单次读取的深度收益。
- 设计：M1，写入器 oracle_random 和 joint_fact（与读取器联合训练），训练 hop 1-3，15,000 步。T0 是用同一代码版本重训的 M1-L4，作参照。T1 固定 $L=8$ 训练，对 hop $h$ 的问题在 $s=h,\dots,8$ 的每一步都加答案损失。T2 在 T1 上改用粘滞更新

  $$
  z^{s+1}=z^{s}+g_s\big(f(z^{s})-z^{s}\big),\qquad g_s=\sigma\!\left(a\,\frac{\lVert UMQz^{s}\rVert}{\lVert u\rVert}+b\right)
  $$

  其中 $f$ 是原来的读取更新。确认集 eval seed 999007。
- 判定：一个臂必须对两个写入器都满足三条：hop 1-3 上 $|\mathrm{Acc}_{L16}-\mathrm{Acc}_{L4}|\le1$ pp；hop 4-8 上 L8 准确率相对 T0 的下降不超过 1 pp；hop 2-3 上 L4 相对 B4@1 的收益 ≥ 3 pp 且 CI > 0（区间水平 $1-0.05/4$）。只对一个写入器通过时，作为写入器特定的结果报告。
- 出处：`docs/prereg/TSM.md`（澄清 C1-C4 只补充失败处理）。

**UNS：unseen 池实体**

- 问题：在 seen 池上测到的深度收益和相对单次读取的优势，在由 unseen 池（编号 768-1023，从未出现在训练中）实体组成的 episode 上是否也出现。这是纯描述性研究，只决定论文范围的措辞。
- 设计：Part A 审计并复算 P1-S 与 F2 已有的 unseen 筛选评估（joint、joint_fact，oracle_random 作对照；M1 与 B4）。Part B 在新的 eval seed 999006 上评估 P2-S-F1 的 M1-L4 与 B4。
- 判定（措辞规则）：unseen 池上 M1 在 hop 2-3 的深度收益 ≥ 3 pp 且区间 > 0，才写“unseen 池实体上也有深度收益”，否则写“在 unseen 池实体上未显示”。无论结果如何，都不写组合对未见实体成立或超出封闭词表。
- 出处：`docs/prereg/UNS.md`。

**NCR：单次读取错误的邻居混淆率**

- 问题：hop 2 的单次读取准确率低于 1/14 的随机线时，错误是否系统地落在第一跳的邻居上。如果是，$D$ 的一部分只是在衡量摆脱这种错误（外部评审 rv-fable C4）。
- 设计：复用 P1-S 与 F2 已有的 $L=1$ 样本（M1 与 B4，hop 2、3），把错误答案按优先级分为第一跳实体 $p_1$、倒数第二个实体 $p_{h-1}$、起点、其他链终点和其他候选。
- 判定：纯描述，不设门限；报告第一跳实体的错误比率及其在错误中的份额，并与均匀猜测的值对照。
- 出处：`docs/prereg/NCR.md`。

### 越过链尾与停机：事后办法没有修好

- **描述性**（H1-H6，筛选集 S4242，无区间）：r=128 oracle_random 的 M1-lin（F1 的 20,000 步 checkpoint）用相对状态变化停止后，hop 4-8 由 L8 的 44.85% 升到 64.41%；hop 1 在 L1、L4、停止后分别为 100%、81.48%、96.62%，部分恢复但没有回到 L1 水平。实现中的自适应停止在全部 48 个格上都比固定 L16 慢；充分收缩证书在 96,000 次评估中无一成立；按真实 hop 数停止也不是准确率上界。出处：H1-H6；`docs/reports/P4S-stopping.md`。
- **描述性**（WP-C4，筛选集）：r=32 learned 码上，分解式四族在三种无标签规则中最好的一种仍损失 hop 1 24.90 至 41.73 pp；未分解的 joint/M1 实际停在 L≈16，没有停止收益。出处：`docs/reports/P4S-stopping-r32.md`。
- **已确认，负面**（HL1-HL4，C999002）：在冻结读取器上事后训练的停机头，6 个主要族中 0 个达标：hop 2-3 收益和 $W$ 都达到要求，但 hop 1 相对 L1 的变化为 −15.70 至 −49.15 pp，18 个 seed 点全部低于 −1 pp。四个族的总体准确率比最佳无标签规则只高 0.88-1.61 pp，与任一步正确的上界还差 10.25-36.34 pp，推理耗时是固定 L16 的 6.26-8.22 倍。这只否定这一种事后停机头，不说明学习型停机不可行。出处：HL1-HL4；`docs/reports/P4S-L.md`。
- **已确认**（JS1-JS4，C999003）：两组 M1 都在训练时随机取 $L\in\{4,\dots,8\}$，RS 组不加正则，RS+J 组对终点读取 Jacobian 的谱半径加正则。越界损失 $S=\mathrm{Acc}_{16}-\mathrm{Acc}_{4}$（hop 1-3）在 oracle_random 上由 −11.27 降到 −2.83 pp，$\Delta S=+8.43$ pp [7.48, 9.42]；在 joint_fact 上由 −3.02 降到 −1.77 pp，$\Delta S=+1.24$ pp [0.22, 2.20]。两者正则后的 $S$ 仍低于 −1 pp，按规则不算消除。代价是 L16 时 hop 4-8 下降 5.55 和 1.44 pp，停止策略的准确率下降 1.04 和 0.68 pp。L16 时谱半径小于 1 的状态比例为 22.2%（oracle）和 92.7%（joint_fact）。出处：JS1-JS6；`docs/reports/JS.md`。

到目前为止，对越过链尾有效的办法仍是固定深度训练（B8、M1-L4）（`docs/reports/P4S-L.md`）。

### LLM 阶段：没有选出 learned 写入器

以下都是 seed 17 在验证集（seed 4242，1,000 个 episode）上的筛选结果，没有区间。是否选中写入器按预注册规则判定，所以“未选出写入器”是登记规则下的结论，具体数值是描述性的。

- **描述性**（LL1）：Pilot-1 中 r=32 的 T1 写入器训练 1,500 步，所有配置的 val EM ≤ 0.3%。出处：`docs/reports/P1L-pilot1.md`。
- **描述性**（LL2-LL4）：输入处有所需信息，rank-32 探针在 tail token 处解码 tail 97.6%，在问题末位置解码起点 99.4%、关系 100%。输出通路可用，直接给出答案码时 lr 3e-3 下 1,500 步 val EM 98.7%。训练到 6,400 步或改用残差流输入都没有救回（EM ≤ 0.1%），key 与 query 的匹配接近随机（top-1 6%-7.5%，随机 6.25%）。出处：`docs/reports/P1L-diagnosis.md`。
- **描述性**（LL5、LL6、LL8、LL9）：W5 训练 32,900 步后 val EM 14.4%（key top-1 82.4%）；读取监督 R 在 r=32 为 12.0%，在 r=128 为 33.5%；W5 在 r=128 为 29.9%。全部低于 0.80 门限和 0.50 的 E=8 重训线。诊断臂 OA 把读取直接换成真实 value，在 r=128 达到 84.0%；它是 value 和输出通路的上限，不是寻址对照。出处：`docs/reports/P1L-writer-fix.md`、`P1L-read-fix.md`。
- **描述性**（LL7、LL9、LL10）：r=128 的 R 用训练时的干净 value 头解码干净 value 为 93.3%，解码实际读取只有 19.7%。W5 在 r=32 对应为 85.4% 和 10.5%，learned key 的平均最大绝对余弦为 0.854。把记忆清零或打乱后 EM 降到接近 0（W5 由 14.4% 降到 0.1% 和 0.2%），说明模型依赖部署的记忆通道，但这些干预不能定位失真的原因。出处：LL7、LL9、LL10。

### LLM oracle 条件：r=32 在确认前就接近无记忆水平

- **描述性**（LP6，训练日志与 Pilot-2，不是确认结果）：17,000 步时（最后 5 个记录的 batch），r=32 的四个记忆读取器 batch 准确率为 0.391%-1.641%，无记忆的 B3-L4 为 0.312%-0.391%，context-retained 的 B1、B2 为 99.375%-100%。r=128 时 M1-L4 为 28.125%-41.250%，B8 为 11.250%-12.812%，B4 为 10.000%-10.781%，B3-L4 为 0.312%-0.625%。Pilot-2 验证集上 r=32 的全词表 EM 为 0.0%-0.3%，候选准确率 7.2%-9.1%，随机水平 7.14%。出处：LP6；`docs/prereg/P1L.md` 修订 B7。
- **描述性**（LP6 容量核查，`scripts/analyze_oracle_capacity.py`）：LLM oracle 的 key 与 value 是两张独立的随机表，从第二跳起读取器要学一张 value→key 的查表。读取器形式的单步映射在样本内拟合，r=32 时 hop-2 寻址为 48.3%，r=128 时为 99.85%；换成旋转 key 后为 99.2% 和 100%。这是一个理想化单步映射的样本内上界。修订 B7 把 r=32 在 hop 1 的失败归因于另外两张随机映射，这一点是推断，没有检验过。出处：LP6。

### 理论与实测的对应

命题 1-11 的确定性数值检查（FP64）在计算节点通过（`docs/reports/WP-T.md`、`WP-T3.md`）。实测与理论的关系见 `docs/paper/evidence_symbolic.md` 末尾的对照表：S7 反驳的是“训练出的 oracle 读取器自动实现精确的一跳一读”这一无条件解读，不反驳命题 3 本身；IS1 与命题 4 的操作性预测一致，但没有测量记忆扰动范数或因果串扰。

### 目前不能写的结论

两份证据表与后续计划 §7 列出了现阶段不能写的话，主要有：

- LLM oracle 与符号 oracle 等价，或符号 oracle 的结果可以搬到 P1-L；
- LLM 在 r=32 下多次读取成功或失败；
- 关于 unseen 实体、封闭词表之外或新实体码的结论；
- OA 是寻址对照；
- B8 与 B4 参数相同，或同秩上的成功证明了相对更大秩的效率；
- learned writer 在 LLM 中不可能、r=32 根本不够、预算不可能是原因。

出处：`docs/paper/evidence_llm.md` Must-not-say list；`plan/followup_2026-10-27.md` §7。
