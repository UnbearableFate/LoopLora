## The project in one paragraph
A recurrent low-rank module ("reader") inside a frozen LM. At one layer, an adapter computes a rank-r state
u from the hidden state and updates a latent z for L reads: z^{s+1} = u + ρ·φ(R z + U M Q z), where M is an
associative memory (decay-first delta rule) filled by a "writer" from facts in the input. A multi-hop question
needs several reads, each moving one hop through the stored facts (vertical latent recurrence; no generated
tokens). The symbolic stage isolates the mechanism with small readers; the LLM stage inserts one module into
Qwen3-0.6B-Base (layer-14 `o_proj`) under a memory-only protocol: the facts are only in M, not in the KV cache;
scoring is full-vocabulary exact match (EM).

## Results so far (pointers only)
Symbolic (mostly r = 32, three seeds, held-out confirmation sets, paired bootstrap CIs):
- Multi-read composition works with oracle codes and with shortcut-free (factorized) learned codes; a single read
  of any tested rank or state size cannot do hops 2–3 with shortcut-free codes (P1-S, F1, F2, P2-S, P2-S-F1).
- An unfactorized learned writer allows a "guess the chain end" shortcut, which larger single reads exploit.
- An unshared unrolled reader (B8, trained at L = 4) is best within the trained depth, worse beyond it;
  fixed-depth training beats mixed-depth training.
- Overshoot: reading past the chain end loses accuracy. Label-free stopping fails (no contraction certificate in
  96,000 episodes), post-hoc learned halting fails (P4-S-L), and a Jacobian spectral-radius penalty at the final
  read state reduces but does not remove overshoot and costs longer walks (JS).
- Memory load: the depth gain shrinks as more facts are stored (IS).
LLM (Qwen3-0.6B-Base):
- The learned writer fails. The information is present at the input positions (probes 97–100%) and the output
  path works (98.7% EM when answer codes are supplied), but the deployed read is distorted: the best learned arm
  reaches 33.5% validation EM at r = 128 (about 12% at r = 32), while oracle addressing reaches 84%. The learned
  keys are highly correlated (mean max |cos| 0.85); the clean value decodes at 93% but the actual read at 20%.
- P1-L tests the reader inside the LM with an oracle random memory at r = 32 and r = 128 (gate: B8 at L = 4 versus
  the single read B4 at the same rank, 97.5% CIs); results after 2026-10-28 22:00 JST.
- A DPFP writer study (keys/queries through the DPFP feature map) is pre-registered: `docs/prereg/DPFP.md`.
