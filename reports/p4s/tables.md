# WP-C3 screening tables

Accuracy is in percent, equally averaging three training seeds and eight hops. All reported accuracy below is screening test data; thresholds were selected on validation.

after update L>=1, predict from z^L; read norm uses UMQz^L relative to UMQz^0; change uses norm(z^L-z^(L-1))/norm(z^(L-1)); stability threshold is consecutive unchanged argmax pairs ending at L; first hit or cap 16

The true-hop oracle is label informed and is not a correctness guarantee. Read-norm stopping costs one extra diagnostic memory read. A certificate c < 1 is sufficient for contraction, not correctness; c >= 1 is inconclusive.

Latency includes prepared-memory reader, candidate prediction and stopping bookkeeping. Each run uses 5 warmups and 20 repeats. Batch-1 summaries equally average one separate query per hop 1–8 and all three seeds; batch-64 summaries average the three seeds. Median/p95 columns are means of run/query-hop percentiles, not pooled percentiles.
